Operator merges clean pull requests under a standing delegation you write once. Put your own words, a `scope` of owners or repositories, and a `date` in `~/.agents/cyberfleet/merge-delegation.md`. For a repository it names, Operator quotes the record with each dispatch and merges each clean pull request without waiting for your reply. It reads the record again before every merge and never writes it. Without the record, Operator still asks before the first merge.
